# Y 的个人空间

一个使用原生 HTML、CSS 和 JavaScript 构建的个人主页与作品展示站点。

🌐 **在线访问：** https://yqh330.github.io/

## 页面结构

- `index.html` — 网站首页
- `about.html` — 关于我
- `projects.html` — 项目展示
- `contact.html` — 联系方式
- `404.html` — 自定义错误页面
- `assets/css/style.css` — 全站样式
- `assets/js/main.js` — 导航交互与页脚年份

## 本地预览

直接用浏览器打开 `index.html` 即可预览。网站没有依赖框架或构建步骤。

## 部署

本项目使用 GitHub Pages。进入仓库 **Settings → Pages**，选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。

## 自定义

可以编辑各页面中的文字，修改 `assets/css/style.css` 调整颜色、布局和组件样式，在 `projects.html` 中添加自己的项目。
